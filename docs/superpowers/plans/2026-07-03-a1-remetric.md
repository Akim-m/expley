# A1 Re-metric Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restate the parity headline in the field's idiom — coverage/effort curves, recall@K with CIs, PR-AUC bootstrap noise bands, aggregated (caveated) IPCW c-index, EPSS-version stamp — per spec §A1 (`docs/superpowers/specs/2026-07-03-pipeline-improvement-design.md`).

**Architecture:** Two small library changes (expose `top_fracs` through the backtest; store/aggregate the already-computed `c_index_ipcw`), one new metrics module (pooled bootstrap CIs), one driver script mirroring `scripts/inwild_epss_parity.py`'s exact arms.

**Tech Stack:** existing backtest/evaluator + numpy bootstrap + matplotlib (figure).

## Global Constraints

- Memory ≤6 GB RSS; measure the driver with `/usr/bin/time -v`.
- No EPSS data in the model arm; EPSS arm = raw `epss_percentile_at_publication` via `score_col`.
- Accuracy claims via the rolling-origin backtest with paired deltas.
- After every task: improvement-log row + commit (user directive).
- IPCW caveat is mandatory wherever `c_index_ipcw` is aggregated: as-of-train vs final-snapshot censoring regimes differ, so IPCW weights are degenerate across them (backtest.py module docstring) — report as secondary, never headline.

### Task 1: `top_fracs` passthrough + per-origin `c_index_ipcw`

**Files:** Modify `src/temporal_exploit/backtest.py` (signature + `operational_metrics` call + `per_origin` dict + `_aggregate`); Test `tests/test_remetric_backtest.py`.

**Interfaces:** `rolling_origin_backtest(..., top_fracs: tuple = (0.01, 0.05, 0.10))` forwarded to `operational_metrics`; `per_origin[i]["c_index_ipcw"]` (float|None) and `aggregate["c_index_ipcw"]` = `{"mean","median","sd","n","caveat"}`.

Steps: failing test (custom fracs appear in `recall_at_top_by_frac`; aggregate carries `c_index_ipcw` with caveat string) → implement → suite → log+commit.

### Task 2: `effort_metrics.py` — bootstrap CIs

**Files:** Create `src/temporal_exploit/effort_metrics.py`; Test `tests/test_effort_metrics.py`.

**Interfaces:**
- `pooled_bootstrap_pr_auc(y: np.ndarray, score: np.ndarray, n_boot=1000, seed=0) -> dict` — `{"pr_auc", "ci95", "n_pos"}`; stratified resampling (positives and negatives resampled separately — Boyd 2013's recommendation at rare prevalence).
- `recall_by_frac_deltas(challenger: dict, baseline: dict, frac: str, horizon: int) -> dict` — paired per-origin deltas for `recall_at_top_by_frac[frac][h]`, same return shape as `paired_origin_deltas`.

Steps: failing tests (known tiny arrays; degenerate all-negative input returns None gracefully; paired deltas match hand-computed) → implement → suite → log+commit.

### Task 3: driver `scripts/inwild_remetric.py` + figure

**Files:** Create `scripts/inwild_remetric.py`; outputs `artifacts/inwild_remetric.json`, `docs/figures/fig_coverage_effort.png`.

Mirrors `inwild_epss_parity.py` setup (handover corpus + data/live in-wild sources + `artifacts/bt_epss` features; structural arm = features minus EPSS cols; EPSS arm = `score_col="epss_percentile_at_publication"`), with `top_fracs=(0.005,0.01,0.02,0.05,0.10,0.15,0.20,0.30)` — the coverage/effort curve grid. Emits per arm: mean coverage at each effort level (h=30,90) with paired deltas + CIs; pooled-bootstrap PR-AUC@30 CIs per arm (the noise band the "tie" sits in); aggregated caveated `c_index_ipcw`; `epss_version_note` stamping the version-era (v3/v4; a "v5 shipped 2026-06-15" survey claim did not verify — RE audit 2026-07-03). Figure: coverage-vs-effort, two panels (30/90d), both arms + delta band.

Steps: write → run under `/usr/bin/time -v` → sanity-check numbers against the parity artifact (recall@{1,5,10}% must reproduce parity's values on shared fracs) → log+commit.
